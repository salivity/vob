How to Burn Split VOB Files to DVD-R Data Disc

Burning split VOB files to a DVD-R as a data disc requires careful attention to file integrity, file system formatting, and playback compatibility. This guide outlines the essential precautions you must take—including selecting the proper UDF file system, preserving sequential naming conventions, managing file size limits, burning at safe write speeds, and understanding the playback limitations of a data disc compared to a standard DVD-Video format.

Distinguish Between Data Discs and DVD-Video

Before burning, understand that burning VOB files onto a DVD-R as a "Data Disc" does not create a standard DVD-Video. Standard set-top DVD players rely on a specific VIDEO_TS folder structure containing .IFO and .BUP files alongside the .VOB files to navigate menus and audio tracks. If you burn VOBs strictly as data:

  • The disc will play on computers and modern media players that support direct container playback.
  • Older or standard standalone DVD players will likely reject the disc or display an "unsupported format" error.
  • If you want standard DVD player compatibility, you must use an authoring tool to create a DVD-Video disc rather than a standard data compilation.

Use the Proper File System (UDF)

DVDs burned as data should use the Universal Disk Format (UDF) rather than older standards like ISO 9660.

  • Standard ISO 9660 has a strict 2 GB file size limit and imposes restrictive filename rules that can truncate your file names.
  • Use UDF 1.02 if you are attempting broad compatibility, or UDF 2.50 for modern PC environments.
  • Most burning software offers a hybrid "UDF/ISO" mode, which provides fallback options for various operating systems.

Maintain Strict Sequential File Naming

Split VOB files are sequential segments of a single video stream (for example, VTS_01_1.VOB, VTS_01_2.VOB, VTS_01_3.VOB).

  • Do not rename split VOB files arbitrarily. Keep their numerical sequence intact so that software players can load and play subsequent files without interruption.
  • Avoid special characters, spaces, or non-standard symbols in the file names, as these can cause read errors on certain operating systems or standalone hardware.

Calculate Disc Capacity Accurately

A single-layer DVD-R is marketed as 4.7 GB, but its actual usable capacity in binary gigabytes (GiB) is approximately 4.37 GiB (around 4,700,000,000 bytes).

  • Ensure the total combined size of your split VOB files does not exceed this 4.37 GiB threshold.
  • Leave at least 100 MB to 200 MB of free space as a safety margin to avoid burning errors near the outer edge of the disc, where write failures are most frequent.

Burn at Moderate Speeds

Burning at the maximum rated speed of your drive or disc increases the likelihood of write errors, buffer underruns, and jitter.

  • Manually lower your burning speed to half of the disc's maximum rated speed (for example, burn a 16x DVD-R at 8x, or an 8x disc at 4x).
  • Burning at a slower, stable speed ensures deeper, clearer pits on the dye layer, resulting in better read reliability and long-term data preservation.

Enable Post-Burn Verification

Always enable the "Verify Written Data" option in your disc burning utility (such as ImgBurn or Nero).

  • Verification compares the burned data on the DVD-R sector-by-sector with the source files on your hard drive.
  • Because split VOB files can suffer from audio/video desynchronization or sudden playback stops if even a small cluster of sectors is unreadable, verification guarantees the burned data is bit-perfect.

Finalize the Disc

Ensure your burning software is set to "Finalize Disc" or "Close Session." Unfinalized or multi-session DVD-R data discs are often unreadable in secondary drives or media players. Closing the disc writes the lead-out track, making the table of contents permanent and globally readable.
